为什么选择 Open-Meteo？需要申请账号吗？

本课采用官方免费非商业接口，无需注册、信用卡或 API Key。网页可以直接请求数据，适合 GitHub Pages。公开调用额度包括每分钟 600 次、每小时 5,000 次、每天 10,000 次；请按需要查询，不要连续自动刷新。学校共用网络时也要控制请求频率。

展示天气时注明 Open-Meteo 来源与数据许可。免费条件可能变化，使用前以官方说明为准。核查日期：2026-11-06。

API 是程序之间约定好的交流方式。本次使用 HTTP GET 请求：把经纬度和所需字段告诉天气服务，它按约定返回数据。API 不一定是 AI；这里的天气来自气象模型，穿衣和巡查建议来自我们编写的规则。

请求的一部分示例用途
接口地址https://api.open-meteo.com/v1/forecast向天气预报服务发请求
地点参数latitude=30.59&longitude=114.30纬度在前、经度在后；不要填反
所需字段current=temperature_2m获取当前时段的气温模型数据
时间设置timezone=Asia/Shanghai本实验使用北京时间
预报长度forecast_days=3获取未来三天

真实响应中的 current.time 是对应的数据时间；“获取时间”表示本页何时收到响应。数据为模型结果，不是学校传感器读数。天气数据：Open-Meteo，CC BY 4.0；本页做字段筛选与规则计算。

从 JSON 中找到你需要的信息

// data 表示接口返回的 JSON 对象
data.current.temperature_2m       // 当前时段气温
data.current_units.temperature_2m // 温度单位
data.daily.time[1]                // 第二个预报日期
data.daily.temperature_2m_min[1]  // 该日最低温
data.daily.precipitation_sum[1]   // 该日预计降水量

数组从 0 开始计数。读取每日数据时，同一个下标对应同一天；先看 daily.time，再读取温度和降水。缺失值不能当成 0。

01 / WEATHER TO OUTFIT

第一部分：今天怎么穿？

13—25 分钟

目标不是只显示温度，而是让同学知道建议是什么，为什么这样建议。先体验参考应用，再做自己的最小版本。

全屏打开穿衣助手 ↗

按顺序完成三步

STEP 1

拿到数据

查询学校附近天气，显示气温、单位、地点和对应时间。先确认是真实返回的数据。

STEP 2

加入规则

按照体感温度给出一条衣物建议；有明显降雨可能时提醒携带雨具。显示判断依据。

STEP 3

加入偏好

增加“怕冷／一般／怕热”选项。改变偏好后立即重新计算，不必再次请求 API。

同一份天气，不同的人可以得到不同建议。

出门时间对应的预报，比“此刻温度”更贴近需求。进阶时增加时段选择，按同一下标读取逐小时体感温度、降雨概率和风速。

参考应用采用什么规则？

示例规则：怕冷时将体感温度减 3℃作为选衣参考，怕热时加 3℃；以 10、18、25℃ 分档生成保暖外套、长袖加外套、轻薄外层、透气衣物等建议。降雨概率达到 50% 提醒带伞。

这些是课堂可修改的经验规则，不是气象机构发布的穿衣指数。测试阈值附近的温度，检查边界是否合理。

02 / WEATHER TO SCHOOL FARM

第二部分：菜园需要观察什么？

25—38 分钟

学校室外种植了白菜、豆角、茄子和莴苣。将同一份天气数据用于农场，制作一个“天气值班员”：预报提示关注点，同学去现场观察并记录。

全屏打开智慧农场 ↗
作物观察方向可设计的巡查任务
白菜降雨前后，观察菜畦排水与叶片雨后记录是否积水
豆角风雨与植株支撑；如有支架，检查固定检查支架及绑蔓处
茄子记录降温前后植株的变化达到设定值后，向农场老师确认措施
莴苣观察温度变化、土壤干湿和生长状态补充一次土壤与植株观察记录

第一版只需要三个功能

  1. 看未来三天：最低温、最高温、预计降水量和最大风速。
  2. 生成一条巡查提醒：例如“预计降水达到设定值，请检查排水沟”。必须展示日期、天气依据、设定阈值与巡查任务。
  3. 记录一次观察：选择作物，填写土壤干湿和观察内容，保存到当前浏览器，并能导出。
先区分三类信息

① 天气 API：区域预报与模型数据。
② 现场记录：同学观察或学校传感器测量。
③ 应用建议：根据数据和规则推导的提醒。

天气预报不能代替菜畦土壤实测。预计降雨不能直接推导出“不用浇水”。本课生成巡查任务，不自动操作灌溉或其他设备。

用教学阈值测试，再由农场老师确认

参考应用以最低温 ≤10℃、一天预计降水 ≥20 mm、最大风速 ≥25 km/h 作为可修改的教学测试阈值。这不是四种作物通用的栽培标准；实际使用要结合品种、生长阶段和现场条件调整。

判断一下：预报明天降雨概率 80%，可以让程序直接决定今天不浇水吗？

卡住时：按现象找到下一步

加载失败：打开 F12 → Network 查看请求地址和状态码；确认网络和经纬度。浏览器跨域错误要看服务规则，不要关闭浏览器安全设置。

429：可能调用过快，停止重复请求，稍后重试；切换规则和偏好时复用已取得的数据。

undefined：对照真实 JSON 的字段名称、数组层级和下标。不要让 AI 猜字段。

数字不对：检查是否对应同一个日期/小时，温度是否为℃，风速是否为km/h，降水是否为mm。
