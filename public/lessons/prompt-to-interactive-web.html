01 / PROMPT EXPERIMENT

说得不同，结果会怎样？

3—15 分钟

同一工具、同一模型、两次新对话；分别保存到 A、B 文件夹。先不要追问修改，保留第一次结果。两组都以“银河网页”为目标。

A / 模糊提示词

把发挥空间交给 AI

提交后观察：AI 怎样理解“好看”和“能交互”？

B / 结构化提示词

把要求写成可以检查的约定

比较的是可执行的细节，不是字数。结构化提示词更明确，但也可能失败；模糊提示词有时会带来意外创意。一次实验不能证明某种写法永远更好。这两组要求详细程度不同，重点观察需求是否被落实。

打开两个作品，自己打分

每项 0—2 分：0 = 缺失或失败；1 = 部分完成；2 = 完成。评分只是课堂观察，不是模型能力排名。

02 / FROM PAGE TO PRODUCT

网页怎样回应你的操作？

15—28 分钟
HTML / 内容与结构

页面有什么

标题、说明、按钮、滑块和画布容器。按钮是一个真正的元素。

<button id="pause">
  暂停旋转
</button>
CSS / 外观与布局

它们长什么样

字体、颜色、间距、大小与手机布局。绿色圆角是样式。

button {
  background: #435d3d;
  border-radius: 24px;
}
JAVASCRIPT / 行为与逻辑

操作后发生什么

响应点击、更新状态，驱动场景。Three.js 是 JavaScript 3D 库。

button.addEventListener(
  'click', togglePause
);
有动画，不一定有交互。自动旋转是一段动画；按下暂停，画面停止并显示“继续旋转”，才形成用户操作与反馈。

事件 → 状态 → 画面

事件
点击暂停按钮→状态
isPlaying = false→反馈
停止自转，按钮变“继续”

“事件”是发生了什么，例如 click（点击）、input（滑块改变）、resize（窗口变化）。“状态”是程序记住的数据，例如是否播放、速度、所选颜色。变量变了以后，还需要代码把变化应用到界面或场景。

03 / DEBUG WITH EVIDENCE
从“坏了”，到“我知道哪里不对”。
28—40 分钟
不要只发“运行不了，帮我修一下”。先固定问题，再给 AI 证据；一次解决一个明确问题。
1 / 复现从刷新开始，按步骤重做
2 / 读报错错误名、信息、文件、行号
3 / 描述预期是什么，实际是什么
4 / 最小修改只改与原因相关的部分
5 / 复测重做原步骤，再查相邻功能
先做一次受控故障实验
下面故意放入一个“按钮响应了，画面没变”的逻辑错误。它是教学模拟，不影响上面的真实银河。请先点“切换红色”，观察，再查看线索。
BUG LAB / 故障练习
状态：blue；画面：blue
预期：状态和星球都变红。实际：请你描述。
线索：控制台没有红色报错，为什么还不对？
程序能执行，不代表逻辑正确。这里只修改了数据，没有把颜色应用到画面。观察缺失的那一步。
function onColorClick() {
  state.color = 'red';
  updateStateLabel();
  // 缺少：renderPlanet(state.color)
}
你是测试员
  1. 刷新或重置练习。
  2. 点击“切换红色”，记录预期和实际。
  3. 应用修复，然后再次点击换色。
  4. 重置，检查状态与颜色是否一起恢复。
  5. 再次换色，确认第二轮仍然有效。
对应真实 Three.js 项目，可能需要补上更新材质或粒子颜色的代码；这里用一个简化界面说明同一种错误。
最小修改 ≠ 只许改一行。它意味着修改范围由已确认的原因决定，保留无关功能。
读懂报错里的三条线索
Uncaught TypeError: Cannot read properties of null
(reading 'addEventListener')
    at app.js:42:8
TypeError：操作的数据类型不符合预期。null：这里没有取到元素。app.js:42:8：出错文件、行号与列号。常见原因包括元素 ID 不匹配，或代码执行时元素尚未创建；需要对照代码确认，不能仅凭错误名下结论。
F12 打开后，我应该找什么？
  1. 打开 Console（控制台），刷新页面，按步骤复现。
  2. 复制第一条与你操作相关的完整错误；点击文件位置查看上下文。
  3. 资源没加载时查看 Network（网络）：文件地址、状态码、失败原因。
  4. 没有报错时，比较状态、界面、实际行为；逻辑错误不一定触发异常。
粘贴相关错误文字与代码；截图可补充画面问题。不要把令牌、密钥和个人信息发进调试记录。
现象先检查什么不要急着做什么
页面黑屏Console 报错、库是否加载、相机位置和场景对象没有证据就重写全部页面
404 / Failed to fetch失败资源的地址、路径、网络和启动方式把资源加载失败当作粒子算法错误
按钮有文字但无反应事件是否绑定、是否被遮挡、状态是否更新只修改按钮颜色
点一次却切换两次监听器是否重复注册、事件是否重复触发用随机延时掩盖问题
